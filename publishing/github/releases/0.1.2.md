# Xaero's World Map: Earth 0.1.2

- Allow Forge to select newer MixinExtras versions supplied by other mods.
- Keep unmapped pixels out of terrain height interpolation and drawing.
- Reuse cached tile coverage masks instead of repeatedly scanning height data.

Choose the JAR matching your Minecraft version and loader. This release includes all ten targets listed in the [README](https://github.com/kltyton/XaeroWorldMapEarth#download-and-installation).

Requires Xaero's World Map and XaeroLib. Fabric releases also require Fabric API. Xaero's Minimap is optional. KltytonUI 1.2.7 and Rhino are bundled.
