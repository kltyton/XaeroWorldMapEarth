# Xaero's World Map: Earth 0.1.3

- Keep detailed block geometry near the map focus and use recorded terrain heights and colors for distant areas. Preserve visible cave openings in surface view and stitch the edges between terrain tiles.
- Add optional 3D terrain to Xaero's HUD minimap. The minimap shares Earth’s map view and uses Xaero’s zoom, orientation, opacity, grid and visibility settings.
- Save the selected view and isometric angles. Double-click the isometric button to reset its angles. Street view still supports free camera movement during the session.
- Add navigation and automatic movement from the world-map context menu, with a 3D route, highlighted destination, remaining distance and a circular terrain scan. Auto-navigation can steer a controlled mount or a player already in flight.
- Add map selection and movement orders for companions when a compatible CompanionCall build is installed.
- Bundle KltytonUI 1.3.1 with NeonJS, and update the build infrastructure to KltytonTemple 1.6.0.

Choose the JAR matching your Minecraft version and loader. This release includes all ten targets listed in the [README](https://github.com/kltyton/XaeroWorldMapEarth#download-and-installation).

Requires Xaero's World Map and XaeroLib. Fabric releases also require Fabric API. Xaero's Minimap and CompanionCall are optional. The release includes KltytonUI's corresponding source and build materials.
