# Xaero's World Map: Earth 0.1.0

A client-side addon bringing native 3D terrain and an Ore-style interface to Xaero's World Map.

## Features

- Isometric, top-down and street views, with rotation, zoom and camera movement.
- Minecraft block models and resource-pack textures for terrain and buildings.
- Ore-style map controls, settings, menus and waypoint interfaces.
- Player heads and optional entity models through Xaero's Minimap.
- World, dimension and cave-layer browsing with your existing Xaero map data.

## Install

Choose one JAR for your Minecraft version and loader, then place it in your client's `mods` folder.

Install **Xaero's World Map** and **XaeroLib (Xlib)**. Fabric releases also require **Fabric API**. **Xaero's Minimap** is optional.

**ApricityUI 1.2.7 and Rhino are included.**
